# VYTOR AI 💜

**Your AI Fitness Companion**

VYTOR AI is a fitness and nutrition app with a modern purple theme.

## Features

* Workout planner
* Workout combinations
* Diet and food tracking
* Progress history
* Reminders
* Data backup

## Theme

Dark background with neon-purple accents.

## Project Status

HTML prototype uploaded. Android APK build setup is the next step.
